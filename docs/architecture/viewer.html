%% Sequence Flow 1 — User Onboarding via Clerk Webhook

sequenceDiagram
    autonumber
    actor Candidate as User / Candidate
    participant Clerk as Clerk Auth Service
    participant API as NestJS Webhook Controller
    participant Mongo as MongoDB (User Collection)
    participant SPA as React 19 Frontend

    Candidate->>Clerk: Completes Sign Up (OAuth / Email)
    Clerk-->>Candidate: Returns Session JWT Token
    Clerk->>API: POST /webhooks/clerk (user.created payload)
    Note over API: Verify Svix Webhook Signature
    alt Signature Valid
        API->>Mongo: Upsert User (clerkUserId, email, role="USER")
        Mongo-->>API: User Created Success
        API-->>Clerk: HTTP 200 OK
    else Signature Invalid
        API-->>Clerk: HTTP 400 Bad Request
    end

    Candidate->>SPA: Redirects to /app/dashboard
    SPA->>API: GET /api/v1/users/me (Bearer JWT)
    API->>Mongo: Find User by clerkUserId
    Mongo-->>API: Return User Profile
    API-->>SPA: HTTP 200 { data: user }

%% Sequence Flow 2 — Theory Session & Async AI Answer Scoring

sequenceDiagram
    autonumber
    actor Candidate as User / Candidate
    participant SPA as React 19 Frontend
    participant API as NestJS Theory Controller
    participant Redis as Redis (Quota & BullMQ)
    participant Mongo as MongoDB (Question Bank)
    participant Worker as BullMQ Async Worker
    participant Mastra as Mastra AI Agent
    participant Provider as LLM Provider Router
(NVIDIA primary, Groq fallback)
    participant NIM as NVIDIA NIM (LLM)
    participant Groq as Groq (LLM, fallback)
    participant PG as PostgreSQL (Sessions & Answers)

    Candidate->>SPA: Selects Topic & Clicks "Start Session"
    SPA->>API: POST /api/v1/theory/session/start
    API->>Redis: INCR quota:userId:YYYY-MM-DD:theory_sessions
    alt Quota Exceeded
        API-->>SPA: HTTP 429 Limit Reached
    else Quota Allowed
        API->>Mongo: Fetch N Questions
        Mongo-->>API: Question List
        API->>PG: Create TheorySession
        PG-->>API: TheorySession Record
        API-->>SPA: HTTP 201 Created { sessionId, questions }
    end

    Candidate->>SPA: Writes Answer & Clicks "Submit Answer"
    SPA->>API: POST /api/v1/theory/session/:id/answer
    API->>Redis: Enqueue Job into "theory-eval-queue"
    API-->>SPA: HTTP 202 Accepted { jobId }

    Worker->>Redis: Pop Job from queue
    Worker->>Mastra: Execute TheoryEvaluatorAgent
    Mastra->>Provider: chat(messages, schema)
    Provider->>NIM: POST /chat/completions (Zod Output)
    alt NVIDIA succeeds
        NIM-->>Provider: JSON { aiScore, aiFeedback }
    else NVIDIA fails (auth/429/5xx)
        Provider->>Groq: POST /chat/completions (Zod Output)
        Groq-->>Provider: JSON { aiScore, aiFeedback }
    end
    Provider-->>Mastra: Evaluation Result

    Worker->>PG: Insert TheoryAnswer & Update TheorySession
    SPA->>API: Poll GET /api/v1/theory/jobs/:jobId
    API->>PG: Fetch Scored TheoryAnswer
    PG-->>API: Scored Answer
    API-->>SPA: HTTP 200 OK { aiScore, aiFeedback }

%% Sequence Flow 3 — Sandboxed Code Execution & AI Code Review

sequenceDiagram
    autonumber
    actor Candidate as User / Candidate
    participant SPA as React 19 Frontend
    participant API as NestJS Coding Controller
    participant Redis as Redis Quota
    participant Piston as Piston Container (127.0.0.1:2000)
    participant Worker as BullMQ Async Worker
    participant Mastra as Mastra Code Reviewer
    participant PG as PostgreSQL

    Candidate->>SPA: Clicks "Run Code"
    SPA->>API: POST /api/v1/coding/run
    API->>Piston: POST /api/v2/execute
    Note over Piston: Executes untrusted code in cgroup sandbox
    Piston-->>API: HTTP 200 { run: { stdout, stderr } }
    API-->>SPA: HTTP 200 OK { output }

    Candidate->>SPA: Clicks "Submit Solution"
    SPA->>API: POST /api/v1/coding/session/:id/submit
    API->>Redis: INCR quota:userId:YYYY-MM-DD:coding_submits
    API->>Piston: POST /api/v2/execute (Hidden test cases)
    Piston-->>API: Test Results (passed: 5/5)

    API->>Redis: Enqueue "code-review-queue"
    API-->>SPA: HTTP 200 OK { status: "accepted" }

    Worker->>Redis: Pop "code-review-queue"
    Worker->>Mastra: Execute CodeReviewerAgent
    Mastra-->>Worker: JSON { timeComplexity: "O(N)", spaceComplexity: "O(1)" }
    Worker->>PG: Insert CodingAnswer
