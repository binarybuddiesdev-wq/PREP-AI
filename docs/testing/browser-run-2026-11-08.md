## Defects found and changes made

1. **PDF ingestion rejected valid PDFs containing NUL bytes.** The PostgreSQL `text` field cannot store NUL characters. The chunker now replaces NULs with spaces before tokenization, and a regression test covers this input. The DSA PDF was reindexed successfully.
2. **PDF retrieval filtered every chunk for a real question-generation request.** The default cosine-similarity cutoff was `0.7`, while observed relevant candidates scored at most about `0.316`. The configurable default is now `0.15`; the environment example and tests were updated. This enabled grounded generation in the browser-created session.
3. **Mastra prompt-injection validation rejected its detector's own output format.** The detector was returning a bare array while Mastra validates an object schema. The guard now requests the expected structured JSON object and explicitly describes that output shape. Unit tests cover the configured instructions and structured-output mode.
4. **PDF Study polling stopped while the browser tab was hidden.** Chrome reported `document.visibilityState === "hidden"`; TanStack Query pauses interval polling in the background unless enabled. PDF question polling now continues in the background only for PDF sessions. A UI integration test asserts that option. The actual generated question response was verified through the signed-in browser, but a new session cannot be started today without exceeding the account's daily quota.
5. **Late failed-job reconciliation could overwrite a ready PDF session.** The observed session has persisted, fetchable questions, while its retained BullMQ job record reports `AI token budget service is temporarily unavailable`. The underlying transient budget-service cause could not be established from available logs. The worker's terminal failure update now uses a conditional state transition from `queued` or `running`, so it cannot replace an already-ready session with `failed`; a regression test covers this case. The stale failed queue record itself was left untouched.

## Remaining limits

This pass does **not** establish that every feature is complete or issue-free. In particular, it did not verify a fresh PDF Study session through visible question answering and AI evaluation, use the second selected React PDF in a citation, exercise every PDF with generated questions, or test all routes and responsive/error cases. A background job reported a transient AI token-budget service error even though its session reached Ready; the ready session remains usable, but that underlying transient error is still unexplained. The user's nine PDFs remain in Library; no quota or existing account data was reset or deleted.
