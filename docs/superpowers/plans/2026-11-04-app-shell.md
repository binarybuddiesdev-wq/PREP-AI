# Authenticated App Shell Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the reference-matched authenticated shell around implemented dashboard and settings routes.

**Architecture:** `AuthenticatedLayoutPage` composes React Router location/navigation, Clerk session and user menu, and the Redux-backed theme preference. The controlled `AppShell` in `components/layout` renders the responsive collapsible sidebar, route title, theme action, user menu, and page content. Only routes that exist are interactive; prototype destinations for unfinished features are visibly disabled.

**Tech Stack:** React 19, React Router, Clerk, Redux Toolkit, Tailwind v4, lucide-react, Vitest, Testing Library.

**Spec:** [Project tracker Phase 1](../../project-tracker.md#phase-1--public-entry-app-shell-authentication-and-setup), [HTML app shell](../../../prepai-ui.html), [ADR-0009](../../adr/0009-frontend-layers.md).

## Global Constraints

- Preserve the seven-layer import rules in `ui/CLAUDE.md` and ADR-0009.
- Components receive route callbacks and auth/theme UI through props; no router hooks, Clerk hooks, Redux, or API access in components.
- Server state remains TanStack Query; theme preference remains Redux Toolkit.
- Only Dashboard and Settings routes are currently implemented; do not point visible active controls at missing screens.
- Preserve loading, retry/error states and existing route protection.

## Review Focus

- The active nav item and title must match the current route, including browser back/forward navigation.
- Mobile navigation must close after selection and through its backdrop/close control.
- Sidebar collapse must not hide accessible names or persist incorrectly across viewport changes.
- Clerk user menu must remain available at desktop and mobile widths and retain sign-out.
- Theme toggle must use the existing Redux preference and remain persistent.
